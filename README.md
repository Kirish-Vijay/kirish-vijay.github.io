# kirish-vijay.github.io

The root of the site that hosts [Effort](https://kirish-vijay.github.io/effort/) (from the `effort` repo).

- `.well-known/assetlinks.json` vouches for the Effort Android app (`io.github.kirishvijay.effort`, matched by its signing key), so it can use the same fingerprint / Face ID sign-in (passkeys) as the website.
- `index.html` sends visitors on to `/effort/`.
